# Баня 5×4 с мансардой — проект и 3D-модель

**3D-модель (открыть в браузере, можно установить на телефон):** https://vitaliysvatko.github.io/Banya-claude/

Интерактивная модель каркаса и бани «под ключ»: вращение и масштаб пальцами, разбор по доскам, 16 этапов сборки, срезы, слои отделки, терраса. После первого открытия работает без интернета; на Android — «Установить приложение», на iPhone — «Поделиться» → «На экран “Домой”».

## Документы (папка `docs`)

| Файл | Что внутри |
|---|---|
| `banya-albom-ver37.pdf` | Основной альбом, вер.37 (27 листов): планы, фасады, разрезы, конструкции, расчёт, полы, отделка, терраса, пол парной |
| `banya-karkas.pdf` | Проект каркаса: схемы стен, перекрытия, стропил, узлы, ведомость |
| `banya-sborka.pdf` | Проект сборки: 16 этапов с 3D-кадрами, контроль, график |
| `banya-materialy.pdf` | Описание материалов и раскрой досок |
| `banya-lestnica-ver2.pdf` | Винтовая лестница Ø1200 на металлическом каркасе |
| `banya-etapy.pdf` | Этапы строительства и бюджет по этапам |
| `banya-smeta.xlsx` | Смета по этапам (формулы, цены можно менять) |

Цены и расчёты — ориентировочные; узлы и крепёж показаны как принцип, значения подтверждает конструктор.
